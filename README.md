.# Predictive Analytics Using Historical Data

## Revenue Forecasting Using Linear Regression

### Project Overview

This project focuses on using historical monthly revenue data to analyze trends and forecast future revenue using predictive analytics.

### Objectives

* Clean and preprocess historical revenue data.
* Analyze historical revenue trends.
* Build a predictive model using Linear Regression.
* Evaluate model performance using MAE, RMSE, and R² Score.
* Visualize actual and predicted revenue.
* Forecast revenue for the next six months.

### Tools & Technologies

* Python
* Google Colab
* Pandas
* Scikit-learn
* Matplotlib

### Methodology

The historical revenue data was preprocessed and converted into a suitable format for analysis. A numerical month number was created to represent the chronological order of the data. The dataset was divided into training and testing sets using an 80:20 split.

A Linear Regression model was trained using the historical data and evaluated using standard regression metrics.

### Model Evaluation

| Metric   |  Result |
| -------- | ------: |
| MAE      | 8150.74 |
| RMSE     | 8709.29 |
| R² Score | -0.0224 |

### Future Forecast

The trained model was used to forecast revenue for the next six months. The forecast results provide an estimated view of future revenue based on the historical trend.

### Conclusion

This project demonstrates how historical data and predictive modeling can be used to analyze revenue trends and generate future forecasts. It provides practical experience in data preprocessing, regression modeling, model evaluation, visualization, and predictive analytics.
